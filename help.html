How to play

Each player gets one card. One person keeps the call sheet, reads an item, and checks its box. Players mark that square if they have it. Before you start, agree on a line, two lines, or a full card. The card id and the game seed are printed on every card, so you can check a winner against the call sheet.

How to print

Download the PDF, then print at 100% / Actual size. Do not choose “Fit to page.” The call sheet has a square that should measure exactly 1 inch. If it is smaller, the dialog scaled the page. Pick Letter if you have US paper, or A4 if you have A4. The cards keep a half-inch margin so a Letter file on A4 paper, or the other way around, still has room at the edge.

The free version and Pro

The free version makes up to 10 word cards, in the Everyday and Christmas themes, with a small footer line. Pro is a lifetime unlock for up to 500 cards, pictures in the squares, and no footer. Lifetime Pro is $19.99. Online checkout is not open yet, so the button says “Pro coming soon.” When checkout opens, that same button goes to the purchase page. You will get a code, or a link that ends in #unlock=.

How to unlock

  1. Open the unlock link, or paste the code into “Paste a code” and choose Unlock.
  2. The page should say Pro is unlocked and show the licensed first name.
  3. It stays in this browser until you choose “Remove unlock from this browser.”

A private window does not keep the unlock. Open the link again there. If a code was shared in public and revoked, the page says so. Changing one character makes the code invalid.

Same cards again

The seed is the short code on the PDF, like KJ4P-92. The same words, in the same order, with the same grid, free-space choice, and seed, always make the same cards. Choose New seed when you want a different shuffle.

Pictures and emoji

Pictures are part of Pro. PNG, JPEG, and WebP are shrunk in the browser. HEIC photos are converted here when the browser can do it. If it cannot, export the photo as JPEG and upload that. Emoji are drawn in your device’s emoji style, so they will not look identical on every phone.
