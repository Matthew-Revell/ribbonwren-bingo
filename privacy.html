Privacy

There is no server, no account, and no database behind this page. There is nowhere to sign up, and the page never asks for an email address.

Your word list and pictures stay in your browser. They are not uploaded. The last list and settings are saved in this browser’s local storage so a reload does not wipe your work. Clear my data removes that saved list and any unlock stored here.

There are no analytics and no trackers. Fonts and pictures on the page come from this same site.

The host sees ordinary web requests, the way any website host does. We do not receive those logs. The page asks this site for its own files, including revoked.json, which is a list of unlock ids that should no longer work. If that file cannot be loaded, a code can still unlock, and the page will check again next time you are online.

If you unlock Pro with a signed code, this browser saves that code, including the first name printed on it, so it can show who it is licensed to. Clear my data removes it. A private window starts blank.

Checkout is a separate page. This app does not create a buyer account and does not ask for an email address. If you paste a license key, this page sends that key and a short device name, such as “Ribbonwren Bingo - Chrome,” to Lemon Squeezy (api.lemonsqueezy.com) to activate or check it. The reply can include the buyer’s name and email. This page does not store that name or email. It keeps the key, a device id, and the time of the last successful check, so Pro can stay unlocked for 14 days without a connection. “Deactivate this device” tells Lemon Squeezy to free that activation. “Remove unlock from this browser” and “Clear my data” only forget this browser’s copy.
